# Brand Assets

Este diretório contém a identidade visual da Ethos.

**Antes de qualquer trabalho visual, verificar se os arquivos abaixo existem.**
Se não existirem, não inventar — perguntar ao time.

## Arquivos esperados

- `colors.md` — paleta de cores (hex, uso de cada cor)
- `typography.md` — fontes (heading + body), tamanhos, pesos
- `logo.svg` — logotipo oficial
- `logo-dark.svg` — versão para fundos escuros (se aplicável)

## Placeholders

Enquanto assets reais não existem, usar:
- Imagens: `https://placehold.co/WIDTHxHEIGHT`
- Logo: logotype tipografado com a fonte heading escolhida
